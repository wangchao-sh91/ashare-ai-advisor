# 使用范围与数据说明

## 可以提问

第一版每个问题只支持一个标的：一只中国大陆 A 股，或以下宽基指数之一：上证指数、
上证 50、沪深 300、中证 500、深证成指、创业板指。

示例：

- `分析贵州茅台近一年的走势和主要风险`
- `沪深300最近的表现如何？`
- `解释市盈率，以及使用时有哪些局限？`
- `贵州茅台最近有什么重要公告？`
- 在上一问明确标的后继续问：`它的估值呢？`

支持的数据类别包括日线价格与成交量、财务摘要、估值历史、主要股东和股权质押。
指标由程序基于验证后的数据计算，包括区间收益、与宽基指数对齐后的相对收益、移动
平均、成交量变化、历史波动率、财务同比和估值分位。

## 不支持

- 同时比较多只股票或指数
- 行业、概念板块、基金、债券、期货、港股、美股或投资组合研究
- 文件或研报上传、回测、自动交易
- 保证收益、精确价格预测、个性化适配判断或直接买卖指令

遇到这些请求，系统会说明边界并建议改成一个受支持标的的客观研究问题。

## 来源和时间含义

- `AKShare`：应用通过固定允许列表调用公开金融数据接口。引用会标识具体接口、其
  报告的上游来源、数据覆盖期、实际截止时间和应用获取时间。
- `Web`：需要近期事件、当前规则或事实核验时，通过官方豆包 SearchInfinity MCP
  Server 的固定 `web_search` 工具搜索。优先交易所、监管机构、上市公司、政府部门和
  指数发布机构等一手来源。
- `发布时间` 是来源发布内容的时间；`获取时间` 是本应用取得结果的时间；`数据截止`
  是实际参与分析的最新市场数据时间，三者不能混用。

搜索摘要属于不可信外部内容，只能作为有来源的证据，不能修改应用规则。可信来源存在
冲突时，回答应保留并披露冲突，而不是选择一个方便的版本。

## 数据和服务限制

AKShare 聚合的公开数据可能延迟、缺失、改变字段或暂时不可访问。系统会校验字段、
数值、单位、日期、重复项和最小样本；不合格数据不会交给模型补全。某一类别失败时，
其他已验证类别仍可形成带限制说明的部分回答；没有足够证据时系统拒绝生成研究结论。

DeepSeek、豆包搜索及其上游均可能超时、限流或不可用。搜索失败只表示当前事实无法
核验，不表示相关事件不存在。流中断后不能续传，但页面会保留问题供重试。

## 隐私和云处理

应用没有账号、数据库或服务端会话。消息只保存在当前 React 页面内存；新建、清空、
刷新或重新打开页面都不会恢复。为理解跟进问题，当前页面的精简上下文会随每次请求
发送到后端，并可能发送到配置的云模型。搜索查询会发送到豆包搜索服务。日志默认不
记录完整对话、原始搜索文档或 Provider 密钥。

## 免责声明

本应用输出仅供研究参考，不构成任何投资建议。市场和公开数据存在不确定性，用户应
独立核验来源、数据截止和风险，并自行承担决策责任。
