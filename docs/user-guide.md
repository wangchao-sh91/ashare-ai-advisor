# 使用范围与数据说明

## 可以提问

每个问题支持一只中国大陆 A 股，或上证指数、上证 50、沪深 300、中证 500、深证成指、
创业板指中的一个宽基指数。也支持稳定的金融知识问题和基于日线与新闻公告的单股走势
分析。若名称、代码或上下文有歧义，系统会先请你确认标的。

示例：`分析贵州茅台近一年的日线走势和主要公告`、`沪深300最近有哪些重要变化？`、
`解释市盈率的局限`。上一问已明确标的时，可以继续问 `它最近有什么公告？`。

## 数据来源与证据边界

- Tushare 免费版 `daily` 是股票日线价格、成交量和成交额的唯一结构化来源。数据按
  `ts_code` 和日期区间获取，成交量从手换算为股，成交额从千元换算为元。
- 豆包 Search Custom HTTPS API 用于财务、估值、主要股东、股权质押、公司事件和宽基
  指数背景。搜索证据必须带可访问 URL、发布者、发布时间（若有）、获取时间和权威性标签。
- 宽基指数只有搜索支撑，不提供确定性指数序列、相对收益或基准比较。
- 搜索中提到的价格不能替代 Tushare 日线，也不能参与程序化价格计算；某类别的证据
  不能补足另一类别。

回答会区分提供方已验证事实、模型分析、类别限制、来源与时效。最终回答由生成模型
依据受限证据上下文自检，不再经过确定性的数字、引用和措辞拦截。`发布时间`、`获取时间` 和
`数据截止` 含义不同。可信来源冲突时会披露冲突。事件与价格相邻只表示时间上的关联，
即使给出事件后 1、3、5 个交易日观察，也不代表事件导致了涨跌。

## 限制与降级

支持的确定性指标仅来自有效日线，例如区间收益、移动平均、成交量变化、历史波动率和
事件窗口观察。不提供基准相对收益、基本面同比、估值分位、盘中行情或精确价格预测。
也不支持多标的比较、板块、基金、债券、期货、港美股、组合研究、回测、自动交易、
个性化适配或直接买卖指令。

Tushare 失败时，价格结论会标为证据不足，但已验证的新闻或财务事实仍可形成部分回答；
豆包搜索失败、限流或额度耗尽时，日线分析仍可保留。所有请求类别都缺少证据时，系统
不会让模型猜测。缓存可能令信息晚于上游，回答应显示实际截止或发布时间。

## 隐私与免责声明

应用没有账号、数据库或服务端会话；消息仅在当前浏览器页面内存中。精简上下文会发送
给配置的云模型，搜索查询会发送给豆包。日志默认不记录完整对话、原始搜索文档或密钥。

输出仅供研究参考，不构成投资建议。市场和公开数据存在不确定性，请独立核验来源、
数据截止和风险，并自行承担决策责任。
